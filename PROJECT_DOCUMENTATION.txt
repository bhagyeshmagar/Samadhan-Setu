 1. PROJECT OVERVIEW
===============================================================================

Samadhan Setu is a full-stack AI-assisted grievance redressal system designed
for municipal and public governance bodies. It processes citizen complaints
through an intelligent pipeline that classifies, prioritizes, routes, and
tracks grievances across multiple departments while maintaining a strict
governance-first philosophy: AI advises, officers decide.

The system is built in two phases:
  Phase 1 — Workflow engine with state machines, task routing, and audit logging
  Phase 2 — AI intelligence layer with DistilBERT, SBERT, YOLOv8, and fusion

===============================================================================
 2. DESIGN PRINCIPLES
===============================================================================

1. GOVERNANCE-FIRST: AI is advisory. Officers lead every decision.
2. AUDITABILITY: Every action (human or AI) is logged with full context.
3. GRACEFUL DEGRADATION: Every AI model has a deterministic fallback.
4. TRANSPARENCY: Citizens see status timelines. Officers see AI explanations.
5. BOUNDED CROWD INFLUENCE: Upvotes inform but cannot override officer judgment.
6. EXPLAINABILITY: Every priority score includes a complete factor breakdown.
7. MODULAR ARCHITECTURE: Each AI service is independent and replaceable.

 3. SYSTEM ARCHITECTURE
===============================================================================

Frontend: Next.js 14 (React 18)
  - Citizen Portal: Lodge, Track, Community pages
  - Officer Dashboard: Task management + AI-ranked queue
  - Admin Oversight: Telemetry, AI health, override statistics

Backend: FastAPI (Python 3.11+)
  - Auth: JWT + Argon2 + RBAC (citizen/officer/admin)
  - Workflow: Complaint state machine + Task state machine
  - AI Pipeline: 9-step orchestrator (background tasks)
  - Routing: Multi-department detection + officer load balancing
  - Analytics: Heatmaps, clustering, hotspot detection

Database: Firebase Firestore
  Collections: users, complaints, tasks, complaint_status_logs,
               audit_logs, category_mappings, departments,
               complaint_ai_results, complaint_embeddings,
               similarity_links, routing_suggestions,
               image_analysis_results, inference_logs,
               complaint_clusters

 4. AI INTELLIGENCE LAYER (PHASE 2)
===============================================================================

4.1 DistilBERT Text Classification
  - Model: facebook/bart-large-mnli (zero-shot)
  - Categories: Roads & Transport, Water Supply, Electricity,
                Sanitation & Waste, Health & Safety, General
  - Fallback: Keyword-based rule engine with weighted scoring
  - Output: category, subcategory, confidence (0-100%), source

4.2 SBERT Semantic Similarity
  - Model: all-MiniLM-L6-v2 (384-dim embeddings)
  - Caching: In-memory + disk (.npy files) + Firestore metadata
  - Threshold: 0.75 for similarity, 0.90 for likely duplicate
  - Advisory links: Officers must approve/reject merges
  - Fallback: Jaccard keyword similarity

4.3 YOLOv8 Image Validation
  - Model: YOLOv8n (nano, CPU-friendly)
  - Detection: COCO classes with category-relevance mapping
  - Output: object count, detected classes, relevance score,
            visual severity (1-3), quality flag
  - Fallback: Skipped gracefully (image analysis unavailable)

4.4 Multi-Modal Severity Fusion
  - Combines text severity (0-10 → 1-3) with image severity (1-3)
  - Adaptive weighting based on text length and image relevance
  - Short text (<20 chars): 35% text / 65% image
  - Moderate text: 50/50
  - Detailed text (>50 chars): 65% text / 35% image
  - Low image relevance (<0.3) halves image weight

4.5 Priority Engine
  Formula:
    Score = 0.30×Urgency + 0.30×Severity + 0.15×CrowdImpact
          + 0.10×SLARisk + 0.10×LocationCriticality + 0.05×History

  Priority Bands:
    Critical (≥2.5) → 12h SLA
    High     (≥2.0) → 24h SLA
    Medium   (≥1.5) → 72h SLA
    Low      (<1.5) → 168h SLA

  Crowd Impact: Bounded at 3.0. Upvotes contribute logarithmically
  (capped at 1.5). Ward density and semantic similarity provide
  additional bounded contributions. Anti-brigading by design.

4.6 AI-Assisted Routing
  - Primary department from AI category
  - Secondary departments from text keyword detection
  - Suggested officer: least-loaded in primary department
  - Override support: officer can override with logged reason
  - Status: pending → accepted / overridden

4.7 AI Pipeline Orchestrator
  9-step pipeline running as FastAPI background task:
    1. Text Intelligence (DistilBERT + urgency/severity)
    2. SBERT Similarity Detection + auto-linking
    3. YOLOv8 Image Analysis (if images exist)
    4. Multi-Modal Severity Fusion
    5. Context Gathering (ward density, dept backlog, repeats)
    6. Priority Calculation (6-factor formula)
    7. AI Routing Suggestion
    8. Store Results (complaint_ai_results collection)
    9. Log Inference (inference_logs collection)

  Each step is independent. Partial failures don't crash the pipeline.

 5. API REFERENCE
===============================================================================

Auth:
  POST /api/auth/register     Register new user
  POST /api/auth/login        Login (JWT token)
  GET  /api/auth/me            Current user profile

Citizens:
  POST /api/complaints/               Submit complaint (triggers AI)

 7. DEPLOYMENT
===============================================================================

Requirements:
  - Python 3.11+, Node.js 18+
  - Firebase Firestore project
  - 2-3 GB RAM minimum (for AI model loading)

Environment Variables:
  FIREBASE_CREDENTIALS_PATH    Path to Firebase service account JSON
  SECRET_KEY                   JWT secret (CHANGE IN PRODUCTION)
  CLASSIFICATION_MODEL_NAME    Default: facebook/bart-large-mnli
  SBERT_MODEL_NAME             Default: sentence-transformers/all-MiniLM-L6-v2
  SIMILARITY_THRESHOLD         Default: 0.75
  EMBEDDING_BATCH_SIZE         Default: 32

Deployment Targets:
  - Railway, Render, AWS (Free Tier compatible)
  - CPU-only inference (no GPU required)
  - AI models download on first startup (~500MB)
