                              PROJECT OUTCOMES
================================================================================

PROBLEM SOLVED
--------------
Samadhan Setu addresses critical challenges in public grievance management:

1. AUTOMATED COMPLAINT CLASSIFICATION
   - AI automatically categorizes complaints into departments
   - Hybrid approach: ML + Rule-based fallback for reliability
   - Categories: Roads & Transport, Water Supply, Electricity, 
                 Sanitation, Public Safety, Healthcare, Education, etc.
   - Accuracy: 85%+ with confidence thresholds

2. INTELLIGENT PRIORITY ASSESSMENT
   - Automatic urgency detection using NLP
   - Severity scoring based on context and keywords
   - Formula: Priority = 0.4×Urgency + 0.4×Severity + 0.2×CrowdImpact
   - SLA deadlines: High (24h), Medium (72h), Low (7 days)

3. DUPLICATE DETECTION
   - SBERT-based semantic similarity matching
   - Prevents redundant complaints (75% similarity threshold)
   - Saves officer time and resources
   - Example: "Water leaking" ≈ "Burst pipe" detected as similar

4. PROOF-OF-RESOLUTION SYSTEM
   - Officers upload verification images
   - Citizens can rate resolutions
   - Creates accountability trail

5. AI-POWERED ANALYTICS
   - Heatmaps showing issue density by location
   - Recurring issue detection via clustering
   - Department performance metrics
   - Trend analysis over time

================================================================================
                              HOW TO RUN
================================================================================

PREREQUISITES:
- Python 3.9+
- Node.js 18+
- PostgreSQL 14+
- 4GB RAM minimum (8GB recommended)
- 3GB disk space (for AI models)

BACKEND:
  cd backend
  python -m venv venv
  .\venv\Scripts\Activate.ps1
  pip install -r requirements.txt
  python create_db.py
  python seed_data.py
  uvicorn app.main:app --reload --port 8001

FRONTEND:
  cd frontend
  npm install
  npm run dev

ACCESS:
  Frontend: http://localhost:3000
  Backend API: http://localhost:8001
  API Docs: http://localhost:8001/docs
